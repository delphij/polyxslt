|---|---|

| Instructions | `apply-templates`, `attribute`, `choose`, `copy-of`, `element`, `for-each`, `if`, `sort`, `text`, `value-of`, `variable`, literal result elements with attribute value templates |

| XSLT functions | `current` |
| Output methods | `html`, `xml`, `text` |

`mode` attribute, attribute sets, the `namespace` axis, and the XSLT functions not listed
above. See [DIVERGENCES.md](DIVERGENCES.md) for differences in behavior.
